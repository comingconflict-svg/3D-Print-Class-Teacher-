# Lesson 12 — Finish, present, next version

**Time:** 45 minutes main lesson  
**Goal:** Students finish or freeze the mini-project, slice a printable version, and say what they would change in v2.

## Learning targets
1. Open Lesson 12 from the student repo.
2. Freeze scope. No new features after minute 10.
3. Export and slice on the Q2 profile.
4. Give a 45-second stand-up: what it is, who it is for, one problem, one next change.
5. Turn in the file with the class name pattern.

## Freeze rule
If it is 80% useful, print that. A finished simple hook beats an unfinished giant project.

## Teacher prep
- [ ] Queue space for overnight prints
- [ ] Timer for stand-ups
- [ ] Lesson 11 WIP files available
- [ ] Lesson 12 student file is in the student repo

## Agenda

### 0:00–0:05 — GitHub + freeze
Open Lesson 12. Say the freeze rule twice.

### 0:05–0:28 — Finish and slice
Group, flat face, Preview, time check. Cut down 5-hour jobs now.

### 0:28–0:42 — 45-second stand-ups
What is it? Who is it for? What almost failed? What would v2 change?

### 0:42–0:45 — Turn-in
YYYY-MM-DD_Firstname_MiniProject_v1.stl plus the Lesson 12 sheet.

## Success check
A sliced file on the Q2 profile and a spoken next-change sentence.
