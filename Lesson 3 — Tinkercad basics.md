# Lesson 3 — Tinkercad basics

**Time:** 45 minutes main lesson  
**Goal:** Students can build a simple solid from primitives, cut a hole, add text, and export an STL that Orca will accept.

## Learning targets
1. Open this lesson’s files from the student GitHub repo.
2. Use move, rotate, scale, align, and group.
3. Switch a shape to Hole and group to subtract.
4. Keep a part printable: 3 mm minimum thickness, flat on the workplane, no floating pieces.
5. Export STL using the class file name.

## Design challenge
Name tag / bag tag
- No larger than 70 × 35 × 5 mm
- Thickness 3–5 mm
- Hole 5 mm
- Letters raised or inset about 1 mm
- Flat on the plate
- No floating letters

## Agenda

### 0:00–0:05 — GitHub + last lesson’s prints
Open the Lesson 3 student file. Look at Lesson 2 prints.

### 0:05–0:18 — Tinkercad demo
Show only: workplane, box, cylinder, solid vs hole, align, group, exact mm size, text, export STL.

Say: Hole is a cookie cutter. If you do not Group, the hole does nothing. Ungrouped letters fall off in the slicer.

### 0:18–0:40 — Students build
Checklist: flat, grouped, hole through, thickness at least 3 mm, name readable.

Stuck students get a starter box 60 × 30 × 4 mm and only add initials plus a hole.

### 0:40–0:45 — Export
File name: YYYY-MM-DD_Firstname_Nametag_v1.stl

## Common failures
| Problem | Fix |
|---|---|
| Letters fall off in Orca | Select all, then Group |
| Hole is only a dent | Cylinder taller than the tag, Hole, Group |
| Paper-thin tag | Height 4 mm |
| Giant tag | Cap at 70 mm |

## Success check
One grouped, flat, holed name tag exported as STL.
