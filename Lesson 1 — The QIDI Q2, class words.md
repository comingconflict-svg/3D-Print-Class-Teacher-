# Lesson 1 — The QIDI Q2, class words, and GitHub

**Time:** 45 minutes main lesson  
**Goal:** Students can name the main parts of the Q2, follow shop rules, recognize the class software, and get this lesson’s files from the student GitHub repo.  
**They do not design anything original today.**

## Learning targets
By the end of the hour a student can:
1. Point to nozzle, hotend, extruder, PEI plate, bed, belts, Z lead screws, touchscreen, and chamber door.
2. Explain: "The Q2 is a CoreXY FDM printer. Two motors share X and Y. The bed moves in Z. Plastic is melted and stacked in layers."
3. State the shop rules without reading them.
4. Open the student GitHub repo, find Lesson 1, and open the student sheet.
5. Say what the Q2 touchscreen, OrcaSlicer, Tinkercad, and GitHub are for.

## Materials
- QIDI Q2, powered, door closed, idle at the start
- One good PLA print and one failed print
- Glossary (print or GitHub)
- Parts scavenger list
- Student repo URL on the board
- Teacher repo URL labeled teachers only
- Laptops with a browser and OrcaSlicer
- Tinkercad class join code

## Teacher prep
- [ ] Student repo is public, or every student has access
- [ ] Lesson 1 student file is in the student repo
- [ ] Q2 plate clean, PLA loaded
- [ ] Short demo print ready around minute 18
- [ ] Tinkercad join code on the board
- [ ] OrcaSlicer demo laptop: Qidi Q2, 0.4 mm

## Safety
1. Nozzle and bed burn. Do not touch metal inside the chamber during or right after a print.
2. Door stays closed while the toolhead is moving.
3. If it looks wrong, tell the teacher. Do not yank the print.
4. Scraper points down and away from your other hand.
5. PLA only unless a teacher says otherwise.

## Agenda

### 0:00–0:05 — Arrive
Write both repo names on the board. Circle the student repo.

### 0:05–0:18 — Q2 walkaround
Pairs use the scavenger list. Glass only unless you invite one pair with the machine idle.

Find: touchscreen, chamber door, PEI plate, heated bed, nozzle, hotend, extruder, filament + runout sensor, toolhead, belts, X rail, Z lead screws, part cooling fan, camera if present.

Board sketch:

Bed moves Z only
Toolhead moves X and Y using two belts (CoreXY)
Filament → extruder → hotend → nozzle → layer on plate


Q2 facts once: 270 × 270 × 256 mm, 0.4 mm nozzle, direct drive, load-cell leveling, enclosed chamber.

### 0:18–0:25 — Start the demo print
Touchscreen: Home / Files / PLA / Start. Watch the first layer for two minutes.

### 0:25–0:38 — GitHub navigation
Say: GitHub stores class folders online. A repo is one project. Teachers plan in the teacher repo. Students get worksheets from the student repo.

Live demo, then students copy:
1. Open the student repo URL
2. Point at repo name, green **Code** button, README
3. Open only this lesson’s file
4. Open the Lesson 1 student sheet
5. Show **Code → Download ZIP**
6. Flash the teacher repo for five seconds

Do not teach clone, commit, branch, or pull request today.

### 0:38–0:45 — Software map + terms
| Tool | Job |
|---|---|
| GitHub student repo | Get class files |
| Q2 touchscreen | Run the printer |
| OrcaSlicer | Turn a model into layers |
| Tinkercad | Design a model |

If time: join Tinkercad and drop one box. No export.

Terms: What melts the plastic? What does the bed do? STL or G-code — which does the printer run? Which repo do students use? Name one thing that burns you.

## Success check
Point to five Q2 parts and open the Lesson 1 student sheet on GitHub.

## Do not do today
Student-designed models. Slicer settings. git commit. Uploading files.
