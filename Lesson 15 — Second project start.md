# Lesson 15 — Second project start

**Time:** 45 minutes main lesson  
**Goal:** Students start a second small project using skills from Lessons 1–14.

## Learning targets
1. Open Lesson 15 from the student repo.
2. Choose an idea that can finish next lesson.
3. Reuse measure, clearance, orientation, and strength rules.
4. Start CAD or a legal remix in class.

## Allowed
Anything useful that fits 90 mm and about 3 hours. Two-part objects are encouraged.

## Not allowed
Weapons, copyrighted movie-accurate helmets, prints that will block the class queue all week.

## Teacher prep
- [ ] Lesson 14 prints on the table as examples of “done enough”
- [ ] Lesson 15 student file is in the student repo

## Agenda

### 0:00–0:05 — GitHub
Open Lesson 15.

### 0:05–0:15 — Pick and limit
Write the idea. Cut anything too big.

### 0:15–0:45 — Build
Plan plus first body in Tinkercad or a remix with credit.

## Success check
A started model and a plan that can finish in Lesson 16.
