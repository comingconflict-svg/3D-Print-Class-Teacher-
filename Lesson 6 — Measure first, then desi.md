# Lesson 6 — Measure first, then design

**Time:** 45 minutes main lesson  
**Goal:** Students measure a real object, design a part that fits those numbers, and check scale before printing.

## Learning targets
1. Open Lesson 6 from the student repo.
2. Record at least two measurements in millimeters.
3. Build in Tinkercad using typed sizes.
4. Add clearance so a hook, pocket, or hole can accept the real object.
5. Slice on Class_PLA_0.20 or the class PETG profile if PETG is loaded.

## Design challenge — pick one
- Cable hook sized to a measured desk edge
- Phone pocket or stand using measured phone thickness and width
- Bin or tray cell for a marker, glue stick, or USB drive
- Hole plate for a measured screw or peg

Max size this lesson: 90 mm in X or Y. Keep height low.

## Clearance cheat sheet
- Hole around a peg or cable: add 0.4–0.6 mm
- Clip over a desk edge: add 0.3–0.5 mm
- Phone pocket: add about 1 mm to thickness
- If it must be tight, print a tiny test hole first

## Teacher prep
- [ ] Calipers plus rulers
- [ ] Box of everyday objects
- [ ] Lesson 5 v2 prints on the table
- [ ] Demo: measure a marker, type the mm value, add clearance
- [ ] Lesson 6 student file is in the student repo

## Agenda

### 0:00–0:05 — GitHub + pickup
Open Lesson 6. Hand back v2 prints if finished.

### 0:05–0:15 — Measure
Each student picks one object and writes two measurements in mm. Wrong units are the main failure today.

### 0:15–0:22 — Demo typed sizes
Click a shape and type mm values. Board math: 18.4 + 0.6 = 19.0

### 0:22–0:42 — Design
Build the fitting part. Fast finishers import to Orca and check that hole size survived export.

### 0:42–0:45 — Queue
File name: YYYY-MM-DD_Firstname_Measured_v1.stl plus the two measurements on the sheet.

## Success check
Student can say the measured number, the clearance they added, and the number they typed.
