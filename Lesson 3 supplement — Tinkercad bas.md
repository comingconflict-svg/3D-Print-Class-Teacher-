# Lesson 3 supplement — Tinkercad basics

**Use with:** Lesson 3  
**Who:** Students get the matching file in the student repo.

## Purpose
A short Tinkercad map they can reopen later. Lesson 3 stays the name-tag build. This file is the reference.

## Quick overview to say once
Tinkercad is browser CAD. Drag primitives. Type millimeters. Hole is not plastic until you Group. Ungrouped text falls off in Orca.

Point at: workplane, shape panel, solid vs hole, align, group, export STL.

## Voluntary at-home assignment
Assign the ShakeN'Make Tinkercad Tutorial Series as optional homework. Not graded. Not required to finish the name tag in class.

Tell students:
- Start with video 1.
- Videos about group, holes, ruler, align, and export are the useful ones.
- Skip anything about circuits or codeblocks.
- Do not need to watch all 12 videos in one night.

## In class
If time is short, skip the video and keep the name tag. Point them at this supplement and the first video link.
