# Lesson 5 — Critique, iteration, and Orca settings that matter

**Time:** 45 minutes main lesson  
**Goal:** Students inspect last lesson’s prints, name what failed, change one thing, and learn which Orca settings change strength and time.

## Learning targets
1. Open Lesson 5 from the student repo.
2. Critique a print using first layer, walls, warping, stringing, and function.
3. Make a v2. Change one variable only.
4. Compare 15% vs 30% infill and 2 walls vs 3 walls in Preview.
5. Keep Qidi Q2 0.4 mm. PLA or PETG only if that is what is loaded.

## Critique questions
- Did layer 1 stick?
- Are edges sharp or fuzzy?
- Did it warp or lift?
- Is it strong enough for the job?
- Did it actually work?

## Teacher prep
- [ ] Lesson 4 prints labeled on the table
- [ ] A few failed prints if you have them
- [ ] Orca open with two plates: 15% infill and 30% infill
- [ ] Lesson 5 student file is in the student repo

## Agenda

### 0:00–0:05 — GitHub
Open the Lesson 5 student file.

### 0:05–0:18 — Print critique
Each student gets their print or a neighbor’s print. Write three observations and one change for v2.

### 0:18–0:28 — Settings that matter
Slice the same model twice.
- Layer height stays 0.20 mm
- Walls 2 vs 3
- Infill 15% vs 30%
- Brim on or off for tiny footprints
- Supports only if Preview shows air

Board: Change one thing. Then you know what worked.

### 0:28–0:43 — Build v2
Edit Tinkercad or re-slice with one setting change. File name ends with _v2.

### 0:43–0:45 — Queue
Accept v2 files that name the one change on the student sheet.

## Success check
Student can point to one defect and name the one change they made.
