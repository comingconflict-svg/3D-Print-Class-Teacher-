# Lesson 14 — Design for another person

**Time:** 45 minutes main lesson  
**Goal:** Students design a small useful object for someone else, not only for themselves.

## Learning targets
1. Open Lesson 14 from the student repo.
2. Name a user and a need.
3. Measure if the object has to fit something.
4. Keep the usual print rules.
5. Export for the Q2.

## Brief
Make one object for another person in the room, at home, or for the classroom. Keep it kind and practical. No copies of copyrighted characters.

## Limits
- Longest side 90 mm
- Under 3 hours
- Class filament
- Must be usable, not only decorative

## Teacher prep
- [ ] Pair students or let them pick a classroom job (hook, tray, stand)
- [ ] Calipers
- [ ] Lesson 14 student file is in the student repo

## Agenda

### 0:00–0:05 — GitHub
Open Lesson 14.

### 0:05–0:15 — User and need
Write who and what. Teacher kills oversized or unsafe ideas.

### 0:15–0:42 — Build
Measure, model, Preview.

### 0:42–0:45 — Queue
YYYY-MM-DD_Firstname_ForSomeone_v1.stl

## Success check
Student can say who it is for and how that person will use it.
