# Lesson 8 — Orientation and supports

**Time:** 45 minutes main lesson  
**Goal:** Students choose an orientation on purpose and use supports only when Preview still shows air after they rotate the part.

## Learning targets
1. Open Lesson 8 from the student repo.
2. Explain why the first layer face matters more than how the model looks in Tinkercad.
3. Rotate a model in Orca and compare support volume.
4. Decide support or no support with a reason.
5. Keep Class_PLA_0.20 or the class PETG profile.

## Rule of the lesson
Rotate first. Supports second.

## Teacher prep
- [ ] Same model sliced three ways: flat, on its side, standing up
- [ ] One print with ugly support marks
- [ ] One print of the same object with no supports after a better rotation
- [ ] Lesson 7 two-part prints on the table
- [ ] Lesson 8 student file is in the student repo

## Agenda

### 0:00–0:05 — GitHub
Open Lesson 8.

### 0:05–0:15 — Three orientations
Slice the same object three times. Students call out first-layer size, support amount, time, ugly faces.

### 0:15–0:22 — When supports are allowed
Allowed if the part still has air after the best rotation, the student accepts a scar, and the job is still under 2.5 hours.

### 0:22–0:42 — Lab
Students take last lesson’s two-part model or a small downloaded model and find a better orientation.

### 0:42–0:45 — Queue
Only queue files that name the first-layer face on the sheet.

## Success check
Student can point to the face on the plate and say why they did or did not use supports.
