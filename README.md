# Teen 3D Printing Class — Teacher Repo

This is an open-source outline for starting a 3D printing class.

It is a starting point, not a finished script you have to follow word for word. Copy it, teach from it, and change it to fit your students, your printer, and your time.

## Goal
Give kids a real skill and a real machine so they have something to care about making. The lesson plans exist so other teachers can start a class without building the whole thing from zero.

## How these repos work
- This repo is for teachers: full lesson plans, timing, and prep.
- The student repo is for kids: short worksheets they open each class.
- Treat both as templates. Edit names, times, and projects as needed.

## Class tools used in these plans
- Printer: QIDI Q2
- Slicer: OrcaSlicer
- CAD: Tinkercad
- Models: MakerWorld and Printables
- Filament: PLA or PETG unless you choose otherwise

## Using this as an outline
- Keep the safety rules.
- Keep student files short.
- Swap projects if you want. The skills matter more than the exact object.
- The empty Hawk Class Project block at the end of each lesson is reserved time. Fill it or ignore it.
