# Lesson 11 — Mini-project plan and start

**Time:** 45 minutes main lesson  
**Goal:** Students pick one constrained project, write a short plan, and start the model the same hour.

## Learning targets
1. Open Lesson 11 from the student repo.
2. Choose one brief from the approved list.
3. Write user, measurements, print rules, and success test before they sculpt.
4. Start the CAD or remix in class.
5. Stay inside size and time limits.

## Approved briefs — pick one
- Desk object: stand, hook, clip, tray cell, cable comb
- School object: book tab, pencil cup insert, calculator stand
- Two-part object: box + lid or hook + plate
- Remix: download one legal model and change it for a real measurement

Not this lesson: helmets, weapons, full-size props, multi-hour miniatures.

## Limits
- Longest side 90 mm
- Target print under 3 hours
- Class filament profile
- Must have a flat first-layer face
- Must name measurements on the plan sheet

## Teacher prep
- [ ] Brief list on the board
- [ ] Calipers and everyday objects
- [ ] Lesson 11 student file is in the student repo

## Agenda

### 0:00–0:05 — GitHub
Open the Lesson 11 plan sheet.

### 0:05–0:12 — Pick a brief
They write the brief name on the sheet. No switching after minute 12 unless the idea is unsafe or too big.

### 0:12–0:22 — Plan
Fill who it is for, two measurements, hardest print rule, how they will test it.

### 0:22–0:45 — Start building
CAD or remix. Export is optional today if the plan is complete and the model has a first body.

## Success check
A filled plan plus a started model.
