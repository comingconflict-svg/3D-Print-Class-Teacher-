# Lesson 4 — First useful object and printability rules

**Time:** 45 minutes main lesson  
**Goal:** Students design a small useful object in Tinkercad, check it against print rules, and optionally remix one downloaded part.

## Learning targets
1. Open Lesson 4 from the student GitHub repo.
2. Choose between design it and download it.
3. Apply print rules: flat face, thickness, overhangs, clearance.
4. Build a phone stand, cable clip, or hook that could be used.
5. Slice on the Qidi Q2 profile and predict problems from Preview.

## Print rules
1. Park it on a flat face.
2. Nothing thinner than 2 mm for class PLA. 3 mm is safer.
3. Overhangs steeper than about 45 degrees need a rethink or supports.
4. Moving or clipping parts need a gap. Start with 0.3–0.4 mm clearance.
5. If Preview shows plastic in mid-air, fix the model before you print.

## Design challenge — pick one
- Phone stand: readable angle, footprint 80 × 80 mm or less, height 70 mm or less
- Cable clip: hooks onto a desk edge 12–20 mm thick. Measure first
- Wall hook: back plate with two 4 mm screw holes

Shaky students may download a stand or hook and modify it in Tinkercad. Remix still needs designer name and license.

## Teacher prep
- [ ] Calipers or rulers
- [ ] One phone and one cable
- [ ] Lesson 3 name tags on the table
- [ ] A bad model ready (floating letters, thin walls, steep overhang)
- [ ] Lesson 4 student file is in the student repo

## Agenda

### 0:00–0:05 — GitHub + rules
Open the Lesson 4 file. Read the five print rules out loud.

### 0:05–0:12 — Why models fail
Show the bad model in Orca Preview. Students call out broken rules. Then show a clean stand.

### 0:12–0:18 — Measure first
Write phone thickness or cable diameter, desk edge if doing a clip, max size 80 mm.

### 0:18–0:40 — Build or remix
15-minute checkpoint: flat face? walls at least 2 mm? will it fall over?

### 0:40–0:45 — Queue
File name: YYYY-MM-DD_Firstname_Stand_v1.stl or Clip or Hook  
Reject mid-air geometry or 4+ hour estimates.

## Success check
Sliced preview with no floating shells. Student can point to the flat face they chose.
