# Lesson 2 — OrcaSlicer, MakerWorld, and Printables

**Time:** 45 minutes main lesson  
**Goal:** Students can download a legal model, open it in OrcaSlicer on the Qidi Q2 profile, slice it, and read Preview well enough to say whether it needs supports.

## Learning targets
1. Get this lesson’s files from the student GitHub repo.
2. Use MakerWorld or Printables.
3. Check the license before downloading.
4. Import STL or 3MF into OrcaSlicer.
5. Confirm printer = Qidi Q2, nozzle = 0.4 mm, filament = PLA.
6. Use Class_PLA_0.20: 0.20 mm layer, 2 walls, 15% infill, brim on small parts.
7. Slice, open Preview, and explain time, grams, and supports.

## Materials
- Laptops with OrcaSlicer
- Q2 profile already added
- Last lesson’s demo print
- Allowed search words on the board
- Student repo URL
- Place to collect 3MF files

## Teacher prep
- [ ] Qidi Q2 0.4 mm in Orca on every machine

## Approved first downloads
No weapons. No copyrighted movie-accurate helmets.

Searches: calibration cube, phone stand, cable clip, fidget low poly, hook, benchy

Sites: https://makerworld.com and https://www.printables.com

## License talk
- Read the license on the model page
- Classroom use is usually fine on these two sites
- Remix allowed means you may change it later
- Non-commercial means you do not sell the print
- Credit the designer if you share a photo
- If the page is vague, pick another model

## Agenda

### 0:00–0:05 — GitHub
Open the student repo and the Lesson 2 file first.

### 0:05–0:12 — Print autopsy
Where did it touch the plate? Can you see layers? Would this shape have needed supports?

### 0:12–0:22 — Orca tour
Find: printer Qidi Q2 0.4 mm, filament PLA, process 0.20 mm, plate, import, slice, preview, layer slider, supports, time and grams.

Say: STL is the shape. Orca cuts it into layers. The Q2 reads those layers. If Preview looks wrong, the print will be wrong.

### 0:22–0:40 — Download and slice lab
1. Search one approved term
2. Write designer + license
3. Download STL or 3MF
4. Import. Max size this lesson: 80 mm
5. Largest flat face on the plate
6. Apply Class_PLA_0.20 and slice

If estimate is over 2 hours, scale down or pick a smaller model.

### 0:40–0:45 — Collect files
File name: YYYY-MM-DD_Firstname_LibraryModel.3mf

## Success check
Slice one downloaded model on the Q2 profile and explain Preview.

## Common failures
| What you see | Fix |
|---|---|
| Empty plate | Import again; try STL |
| Tiny speck | Scale to 30–60 mm |
| Air in preview | Rotate or enable supports |
| Huge time | Scale down |
| Generic printer | Switch to Qidi Q2 0.4 |
