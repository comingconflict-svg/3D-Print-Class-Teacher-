# Lesson 16 — Second project finish and class close

**Time:** 45 minutes main lesson  
**Goal:** Students freeze and slice the second project, then say one thing they learned and one thing they would teach a new student.

## Learning targets
1. Open Lesson 16 from the student repo.
2. Freeze scope.
3. Slice on the Q2 profile.
4. Turn in a named file.
5. Speak one learning and one teaching point.

## Teacher prep
- [ ] Queue space
- [ ] Timer
- [ ] Lesson 16 student file is in the student repo

## Agenda

### 0:00–0:05 — GitHub + freeze

### 0:05–0:28 — Finish and slice
Same print rules as the rest of the course.

### 0:28–0:42 — Close-out stand-ups
What I made. What I learned. What I would teach a new student.

### 0:42–0:45 — Turn-in
YYYY-MM-DD_Firstname_Project2_v1.stl
